# **README — BGIN‑AVIS Language Pack (Sentinel V2.0)**  
### **Directory:** `VERSION/2.0/AI/bgin-avis/`

This directory contains the **core AVIS language templates** used by Sentinel V2.  
These `.bgin` files define the **BGIN AVIS syntax**, **metadata rules**, and **file‑type‑specific behaviors** that all AI‑generated artifacts must follow.

These templates are used by:

- The AVIS Coordinator  
- The BGIN ingestion engine  
- The FIRE‑GEM writer  
- The AI EDU training tabs  
- Any AI agent generating AVIS‑compliant files  

They serve as the **canonical source** for how each file extension must be structured under AVIS law.

---

## **Files in This Directory**

### **`avis.bgin`**  
The **root AVIS template**.  
Defines the universal BGIN AVIS header, metadata fields, and FIRE‑block structure.  
All other `.bgin` templates inherit from this one conceptually.

Used for:
- Generic AVIS files  
- New file types  
- AI‑agnostic templates  

---

### **`avis-asm.bgin`**  
The AVIS template for **assembly (`.asm`) files**.

Defines:
- Comment style for ASM  
- AVIS metadata formatting  
- FIRE‑block placement  
- Required ACK fields  

Used by:
- Sentinel V2 ASM modules  
- Low‑level FIRE‑GEM routines  
- AVIS‑compliant assembly output  

---

### **`avis-html.bgin`**  
The AVIS template for **HTML (`.html`) files**.

Defines:
- HTML‑safe AVIS comment blocks  
- Metadata embedding rules  
- FIRE‑block compatibility inside markup  

Used by:
- UI renderers  
- Documentation generators  
- AI‑produced HTML artifacts  

---

### **`php.bgin`**  
The AVIS template for **PHP (`.php`) files**.

Defines:
- PHP‑style AVIS metadata comments  
- FIRE‑block placement inside PHP  
- AI ingestion shape for PHP modules  

Used by:
- Sentinel V2 web interfaces  
- AVIS‑aware PHP loaders  
- AI‑generated backend scripts  

---

## **Purpose of This Directory**

This folder is the **language definition layer** for AVIS.  
It ensures that every file generated by AI:

- Has the correct AVIS header  
- Uses the correct comment syntax for its language  
- Contains the correct FIRE‑GEM lock blocks  
- Is safe for ingestion by the BGIN engine  
- Is consistent across all Sentinel V2 modules  

If a file is AVIS‑compliant, it is because it **originated from one of these templates**.

## **Usage**

To create a new AVIS‑compliant file:

1. Select the appropriate `.bgin` template  
2. Copy it into your target directory  
3. Replace the metadata fields  
4. Insert your code above the FIRE!END block  
5. Never modify the FIRE!END lock blocks
